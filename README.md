# SEO Keywords Tool

This tool generates meaningful keyword combinations, analyzes their performance, and provides insights for better SEO optimization.

## Features
1. Combine user-provided keywords into phrases.
2. Analyze search volume, relevance, and competition.
3. Export results as CSV files.

## How to Use
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run the tool: `python main.py`.
